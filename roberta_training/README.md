# RoBERTa Training — Few-Shot Augmented

Fine-tunes `roberta-base` on the rationale-equivalence task with synthetic data
generated by `synthetic_data_generation_improved/` injected into the training
pool.

## Scripts

| File | What it does |
|---|---|
| `run.py` | Loads `reformulated_full.csv`, applies the domain-OOD split (train: dynahate/cad/measure/socialbias/toraman; test: toxigen/gab/anatomy), appends the few-shot synthetic rows from `synthetic_data_generation_improved/reformulated (4).csv`, fine-tunes RoBERTa-base, evaluates on the OOD test split, writes `metrics.json` + `test_predictions.csv`. |
| `evaluate_manual.py` | Loads a trained checkpoint and scores it on the 20-row `manual_labelling.csv` (the same file used as the few-shot seed during data generation — see caveat in `TEST_SETS.md`). |
| `test_negation.py` | 20 hand-written negation-flip pairs sampled from `reformulated_full.csv`. Scores whether the trained model marks them all `unequivalent`. Sanity check for the negation-shortcut hypothesis. |

## Reproducing the headline result

```bash
cd roberta_training
pip install -r requirements.txt

python run.py \
    --synthetic ../synthetic_data_generation_improved/"reformulated (4).csv" \
    --base_csv ../reformulated_full.csv \
    --output_dir runs/roberta_fewshot \
    --epochs 3 --lr 2e-5 --batch_size 32 --max_length 256 --seed 42
```

Best validation `f1_macro = 0.9898` at step 1580 (epoch 2). OOD test results
land in `runs/roberta_fewshot/metrics.json`.

## What's in `runs/roberta_fewshot/`

| File | Size | Meaning |
|---|---|---|
| `metrics.json` | <1 KB | Per-domain accuracy / F1 / AUROC on the 17,691-row OOD test set. |
| `test_predictions.csv` | 12 MB | Per-row predictions on the OOD test set (post_id, domain, label, pred, p_unequivalent). |
| `trainer_state.json` | 7 KB | Full HuggingFace `Trainer` log: per-step loss, LR schedule, eval checkpoints. |
| `config.json` | <1 KB | RoBERTa-base model config. |

The model weights themselves (`model.safetensors` 476 MB, `optimizer.pt` 951 MB)
are not in git — see `EXCLUDED_FILES.md` at the repo root.

## Caveats worth knowing

1. The `reformulated_full.csv` base data has the known mislabeling problem
   documented in `FINDINGS.md` and `audit_results.txt` (≈50% of "unequivalent"
   rows reach the same conclusion as the original). The 50-row few-shot
   augment is too small to dilute this signal — most of what RoBERTa learns
   here is still the structure of the original data.
2. `evaluate_manual.py` evaluates on the same 20 pairs that were used as the
   few-shot seed in `synthetic_data_generation_improved/script.py`. The
   training distribution was conditioned on them, so the manual-eval number
   is not an independent test. See `TEST_SETS.md`.
3. `claude_test_labels.csv` is an independent eval set built by prompting
   Claude with the same instructions used for Qwen (see `TEST_SETS.md`).
